# Public Evidence Library frontend

Buildless files are in `dist/index.html`, `dist/styles.css` and `dist/app.js`. Root supplies all data under `dist/data` and owns Sites configuration, publication, preservation and source-data receipts. The frontend changes no existing workbench or Civic Voice file.

The interface provides Home, starter questions, the complete measure catalogue, direct measure exploration, evidence-reading guidance and an explicitly access-controlled Civic Voice companion link. All information is readable without a guess, answer or consent. The catalogue renders 50 filtered entries at a time. Native source identifiers, units, source years, status and missing values remain visible.

Interactive evidence is lazy-loaded through `data/evidence-index.json`. Top-level or series `hosted_scope_note` is displayed beside the chart. Source-only questions show references rather than an invented plot, while retaining optional private notes. Local workbench paths are not turned into public links.

Charts show the selected native place and year window. They do not aggregate, interpolate, fit a model or create numerical estimates. Suppressed/unavailable/ineligible values are excluded from plots but retained in tables/downloads. Lines join consecutive calendar years only, so Census reporting gaps remain unconnected points. Genuine zeros stay numeric. Sources with no annual year use a native-place snapshot/pooled-period view: original period labels and an open source table, plus CSV/JSON downloads; no year or trend is fabricated. Optional notes use null start/end years for these views. Table and JSON/CSV exports preserve available source fields. When a selected source view supplies at least one finite low/high bound, the table includes “Published lower / upper bounds,” with source units, unavailable sides and any supplied interval-meaning/type text. No confidence interval, error bar or uncertainty estimate is manufactured.

Notes are keyed by public edition, question, measure, native place and source-year window in sessionStorage. Optional expectation, before/after confidence and reflection fields never enter a network request or share URL. Explicit private-review download produces a local JSON file, not a poll or Civic Voice submission. Changing evidence selection opens a different note scope; it does not carry an answer silently to another measure/place. Civic Voice's existing canonical chapter schema is not modified or impersonated.

Frontend fetches only static JSON with omitted credentials. It uses no analytics, third-party rendering package, font service, image generation or answer-upload API. Scripts/styles are external files compatible with a self-only script policy. Dynamic labels and source data use DOM text, and source URLs reject script/file/local-workbench addresses.

Focused tests in `tests/frontend_logic.test.cjs` cover null/zero distinctions, suppressed-source gaps, actual source years, native-place selection, intersecting catalogue filters, private-review scope identity and public source URL boundaries. Run `node --test tests/frontend_logic.test.cjs` and `node --check dist/app.js`. Root owns actual browser and public deployment checks; these logic tests do not establish visual or hosted behavior.
